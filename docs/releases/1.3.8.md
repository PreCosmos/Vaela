Fixes missing Plasma wallpaper settings after desktop containment IDs change.

- Recovers a desktop's missing image from its saved Vaela fallback or a single
  orphaned image wallpaper group. Existing images, other wallpaper plugins,
  panel settings and ambiguous orphan groups are left alone.
- Repairs both the shared Plasma layout and Vaela's private layout at shell
  startup, with a `.pre-vaela-wallpaper-repair` backup beside each changed file.
- Includes regression tests for orphan recovery, fallback restoration, repeated
  launches, preservation of existing settings and ambiguous recovery sources.

Install on Arch Linux / CachyOS:

```bash
curl -fLO https://github.com/PreCosmos/Vaela/releases/download/v1.3.8/vaela-desktop-1.3.8-1-x86_64.pkg.tar.zst
sudo pacman -U ./vaela-desktop-1.3.8-1-x86_64.pkg.tar.zst
```

Log out and back in to apply the wallpaper repair. Select **Vaela** to use Vaela,
or **Plasma** to use the regular desktop. Installation does not restart your session.

This remains an Arch preview: the workspace-bar pointer activation and native
window-resize integration failures reported in 1.3.7 have not been resolved by
this wallpaper change. The release build runs all five CTest suites before
publishing. Live desktop verification is still needed. No Fedora RPM is included.

The binary pins the upstream KWin version it was built against; inspect the
package dependencies with `pacman -Qip` and rebuild if your KWin version differs.
The release includes the source archive, generated PKGBUILD and SHA256SUMS.
